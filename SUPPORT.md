# Support

Before opening an issue:

1. Confirm that the session is Wayland.
2. Run `./scripts/verify.sh`.
3. Read `docs/TROUBLESHOOTING.md`.
4. Include Plasma, KWin, distribution, architecture, GPU, and monitor layout.

Native KWin plugins can require recompilation after KWin upgrades. Re-run `./scripts/install.sh` after an upgrade before reporting a loading failure.
