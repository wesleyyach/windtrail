# KDE Store listing

## Product name

**WindTrail — Animated Mouse Cursor Trail for KDE Plasma**

## Category

KWin Effects

## One-line description

A smooth, customizable wind-ribbon cursor trail for KDE Plasma 6 and KWin Wayland.

## Long description

WindTrail adds a continuous curved ribbon behind the mouse cursor. Unlike classic mouse trails that repeat cursor images, WindTrail generates a smooth wind/slash shape whose width and lifetime react to movement speed.

It includes a native configuration panel with live preview, Crimson Slash, Wind White and Ice Blue presets, custom colors, thickness, intensity, trail duration, minimum activation speed, curve smoothing, and an option to disable the effect in full-screen apps and games.

WindTrail is a native C++ KWin effect. The source package compiles and installs both the effect and its Plasma configuration module. Because native KWin plugins are linked against KWin, users may need to rebuild after KWin upgrades. Installation currently requires downloading the source archive and running the included installer; it is not a one-click KPackage effect.
